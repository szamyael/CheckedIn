# CheckedIn logo

## The idea

The Threshold is an open event entrance with one attendee arriving inside it. It signals participation and a shared
event without drawing a QR code or repeating the old location-pin/check symbol.

## Masters and exports

- `checkedin-symbol-color.svg` — primary mark for products and documents.
- `checkedin-symbol-small.svg` — heavier small-size cut for browser tabs and compact avatars.
- `checkedin-horizontal-color.svg` — primary horizontal lockup.
- `checkedin-horizontal-on-blue.svg` — colour-preserving reverse for campus-blue fields.
- `checkedin-stacked-color.svg` — stacked lockup for square layouts.
- `checkedin-wordmark-color.svg` — standalone custom wordmark.
- `checkedin-app-icon.svg` — square launcher artwork.
- `checkedin-launcher-foreground.svg` — transparent Android adaptive-icon foreground.
- `concepts/` — monochrome concept exploration and size tests.
- `exports/` — black, white, brand-mono, favicon, square, app-icon and web-icon files.

The wordmark is drawn as editable SVG paths, not live text; the symbol uses scalable strokes. Screen previews and
app icons are raster exports of the SVG masters. App-icon tiles are square; iOS and Android apply their own masks.
Request printer-specific CMYK/spot conversion before print use.

## Clear space and size

Leave at least the teal attendee-dot diameter around the horizontal and stacked lockups. Use the full lockup at
96 px wide or larger. Use the small-size symbol at 16–24 px; use the full-size symbol from 32 px up.

## Colours

| Name | HEX | RGB | Approx. CMYK |
|---|---|---|---|
| Campus blue | `#12366A` | 18, 54, 106 | 83, 49, 0, 58 |
| Check-in teal | `#0EB89A` | 14, 184, 154 | 92, 0, 16, 28 |
| White | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 |
| Black | `#000000` | 0, 0, 0 | 0, 0, 0, 100 |

Use the colour master on white or a light neutral. Use the white master on campus blue or a dark neutral. The
black master is for single-colour reproduction. Keep the app icon's blue tile and teal dot intact.

CMYK values are approximate conversions for reference, not printer profiles.

## Avoid

Do not stretch, rotate, recolour, add effects, rearrange the symbol and wordmark, or typeset a replacement wordmark.
Do not place the colour logo on a busy image; use the approved white/reversed version on a calm dark field.
